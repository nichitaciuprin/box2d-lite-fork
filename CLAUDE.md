This is a fork of Box2D-Lite
I created it to better understand how physics works
To understand it, I gradually rewrite, refactor and simplify code.

Box2D-Lite is Erin Catto's small 2D physics engine
Its the original, minimal precursor to the full Box2D library
It was written for the 2006 GDC Physics Tutorial

Project uses ImGui, GLFW, OpenGL and glad

This is a personal fork with in-progress modifications on top of upstream Box2D-Lite
Expect commented-out experimental code
I prefer Allman brace placement style
